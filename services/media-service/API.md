# Media Service – API Contract (v0.1)

Base URL (local): `http://localhost:8000`
Interactive docs: `http://localhost:8000/docs` (generated by FastAPI from the code, so it's always current)

## Auth

Every endpoint except `/health` requires the Supabase access token:

```
Authorization: Bearer <supabase access_token>
```

In the frontend: `const { data } = await supabase.auth.getSession(); data.session.access_token`

Users can only see and change their own photos. Another user's photo returns `404`.

## Upload flow

The file goes from the browser **directly to S3**. The API only issues the upload URL and records the result.

```
1. POST /photos/uploads          → API creates a "pending" photo, returns a presigned S3 URL
2. PUT  <upload_url>             → browser uploads the file bytes straight to S3
3. POST /photos/{id}/complete    → API checks the file is in S3, marks it "uploaded"
                                   (later: publishes media.uploaded to RabbitMQ)
```

## Photo status

| Status | Meaning |
|---|---|
| `pending` | Record created, file not uploaded yet |
| `uploaded` | File confirmed in S3, waiting for processing |
| `processing` | Worker is generating resolutions / reading EXIF |
| `ready` | Done |
| `failed` | Processing failed |

## `POST /photos/uploads`

Start an upload.

**Request**
```json
{
  "filename": "DSC_0042.NEF",
  "content_type": "image/x-nikon-nef",
  "size_bytes": 48213004,
  "project_id": "8a1c2f9e-4b7d-4e2a-9c51-3f0d6b2a7e10"
}
```
| Field | Type | Required | Notes |
|---|---|---|---|
| `filename` | string | yes | 1–255 chars |
| `content_type` | string | yes | JPEG, PNG, TIFF, DNG, CR2, CR3, NEF, ARW, or `application/octet-stream` |
| `size_bytes` | int | yes | 1 byte – 5 GB |
| `project_id` | uuid | no | Links the photo to a client project |

**201**
```json
{
  "photo_id": "f3b9e1d2-6c4a-4f8e-a2b7-1d9c0e5f4a33",
  "upload_url": "https://<bucket>.s3.ap-southeast-1.amazonaws.com/originals/...&X-Amz-Signature=...",
  "method": "PUT",
  "headers": { "Content-Type": "image/x-nikon-nef" },
  "expires_in": 900
}
```

Then upload the file:
```js
await fetch(ticket.upload_url, { method: "PUT", headers: ticket.headers, body: file });
```

**Errors:** `401` bad/missing token · `415` unsupported file type · `422` validation error

## `POST /photos/{photo_id}/complete`

Confirm the S3 upload finished. No request body.

**200** – a [Photo](#photo-object) with `"status": "uploaded"`

**Errors:** `404` not found · `409` file not in S3 yet, or photo isn't `pending`

---

## `GET /photos`

List your photos, newest first.

**Query params**
| Param | Type | Default | Notes |
|---|---|---|---|
| `project_id` | uuid | – | Filter by project |
| `status` | string | – | Filter by status |
| `limit` | int | 50 | 1–200 |
| `offset` | int | 0 | |

**200**
```json
{
  "items": [ /* Photo objects */ ],
  "total": 128,
  "limit": 50,
  "offset": 0
}
```

---

## `GET /photos/{photo_id}`

**200** – a [Photo](#photo-object) plus a short-lived download link (`null` while `pending`):
```json
{
  "...": "all Photo fields",
  "download_url": "https://<bucket>.s3...&X-Amz-Expires=3600&..."
}
```

**Errors:** `404`

---

## `DELETE /photos/{photo_id}`

Deletes the database record and the S3 object.

**204** – no body

**Errors:** `404`

## Photo object

```json
{
  "id": "f3b9e1d2-6c4a-4f8e-a2b7-1d9c0e5f4a33",
  "project_id": "8a1c2f9e-4b7d-4e2a-9c51-3f0d6b2a7e10",
  "filename": "DSC_0042.NEF",
  "content_type": "image/x-nikon-nef",
  "size_bytes": 48213004,
  "status": "uploaded",
  "exif": null,
  "created_at": "2026-10-06T14:02:11.512Z",
  "updated_at": "2026-10-06T14:02:19.870Z"
}
```

`exif` stays `null` until the media worker is built. It will then look like:
```json
{
  "camera": "NIKON Z 6II",
  "lens": "NIKKOR Z 50mm f/1.8 S",
  "iso": 400,
  "aperture": 2.8,
  "shutter_speed": "1/250",
  "focal_length_mm": 50,
  "taken_at": "2026-07-24T18:12:03",
  "gps": { "lat": 1.2903, "lng": 103.8519 }
}
```

## Error format

FastAPI's default:
```json
{ "detail": "Photo not found" }
```
Validation errors (`422`) return `detail` as a list of field errors.
